# Historical GPS ride setup

This guide contains setup and behavior for early app versions and is retained only as a development record. Those version-specific steps are obsolete. Use the current [README](README.md) for version 0.135 instructions and build steps.

The app records phone or Android Auto host locations while a GPS session runs. Automatic session start/stop depends on Android Auto connection state, Bluetooth monitoring, permissions, and Android background limits. Always confirm the running notification before riding and compare recorded distance with the motorcycle trip meter. Use the app while parked for setup and corrections.

The historical instructions below refer to versions 0.5–0.9 and should not be followed for the current app.
