# Historical dashboard photo setup

This guide documents the original photo workflow and is retained only for historical reference. Use the current [README](README.md) and in-app review screens for version 0.135 behavior.

Dashboard photos are processed on-device. OCR results remain suggestions until reviewed and saved. Photos can be re-cropped in the recognition-area editor. Use the app while parked; keep labels and digits inside each crop, and confirm every suggested value before updating fuel estimates.

The instructions below describe early versions and their parser limitations; do not use their version-specific install steps.
